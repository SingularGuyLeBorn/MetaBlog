# 01-基础对话

## 概述

Kimi API 完全兼容 OpenAI 的 API 格式，使用 OpenAI SDK 即可调用。本文档介绍基础的单轮对话调用方式。

## 环境准备

```bash
pip install --upgrade 'openai>=1.0'
```

## 快速开始

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.ai/v1",
)

# 基础对话（非流式）
response = client.chat.completions.create(
    model="kimi-k2-turbo-preview",
    messages=[
        {"role": "system", "content": "You are Kimi, an AI assistant provided by Moonshot AI."},
        {"role": "user", "content": "Hello, what is 1+1?"}
    ],
    temperature=0.6,
)

print(response.choices[0].message.content)
```

## 支持的模型

| 模型名称 | 说明 | 上下文长度 |
|---------|------|-----------|
| `kimi-k2.5` | 最新多模态模型，支持思考模式 | 256K |
| `kimi-k2-turbo-preview` | K2 快速预览版 | 256K |
| `kimi-k2-thinking` | K2 思考模式 | 256K |
| `kimi-k2-thinking-turbo` | K2 思考模式快速版 | 256K |
| `moonshot-v1-8k` | 标准版 8K 上下文 | 8K |
| `moonshot-v1-32k` | 标准版 32K 上下文 | 32K |
| `moonshot-v1-128k` | 标准版 128K 上下文 | 128K |
| `moonshot-v1-8k-vision-preview` | 视觉版 8K 上下文 | 8K |
| `moonshot-v1-32k-vision-preview` | 视觉版 32K 上下文 | 32K |
| `moonshot-v1-128k-vision-preview` | 视觉版 128K 上下文 | 128K |

## 请求参数

| 参数 | 类型 | 必需 | 说明 |
|-----|------|-----|------|
| `model` | string | 是 | 模型 ID |
| `messages` | array | 是 | 消息列表 |
| `temperature` | float | 否 | 采样温度 (0-1)，kimi-k2 默认 0.6 |
| `top_p` | float | 否 | 核采样参数，默认 1.0 |
| `max_completion_tokens` | int | 否 | 最大生成 token 数 |
| `stream` | boolean | 否 | 是否流式输出，默认 false |
| `n` | int | 否 | 生成结果数量，默认 1 |

## 消息格式

```python
messages = [
    {"role": "system", "content": "系统提示词"},
    {"role": "user", "content": "用户输入"},
    {"role": "assistant", "content": "助手回复"},
]
```

角色说明：
- `system`: 系统提示，设定 AI 助手的行为
- `user`: 用户输入
- `assistant`: 助手回复（用于多轮对话）

## 使用环境变量

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ.get("VITE_KIMI_API_KEY"),
    base_url="https://api.moonshot.ai/v1",
)
```

## 错误处理

```python
from openai import OpenAI, APIError, APIConnectionError

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.ai/v1",
)

try:
    response = client.chat.completions.create(
        model="kimi-k2-turbo-preview",
        messages=[{"role": "user", "content": "Hello"}]
    )
    print(response.choices[0].message.content)
except APIConnectionError as e:
    print(f"连接错误: {e}")
except APIError as e:
    print(f"API 错误: {e}")
except Exception as e:
    print(f"其他错误: {e}")
```
