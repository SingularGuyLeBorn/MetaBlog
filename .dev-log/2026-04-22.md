**用户提问**："前端本地有fetch 是啥意思？ 前端应该有这种东西吗？"

## 需求 7：DeepSeek API Key 未生效问题(待修复)

**提出时间**：2026-04-22 ~23:30

**用户原话**："为啥？ 错误：deepseek API Key not configured"

**根因分析**：
`src/theme/api/services/aiService.ts` 第 286 行在**模块顶层**固化了 `import.meta.env.VITE_DEEPSEEK_API_KEY`：

```typescript
const MODEL_CONFIGS = {
  'deepseek-chat': {
    // ...
    apiKey: import.meta.env.VITE_DEEPSEEK_API_KEY || '',  // ← 编译时快照
  }
}
```

Vite 编译后这个值被替换为当时的实际值(空字符串)，后续即使修改 `.env`、重启 dev server，只要 `aiService.ts` 本身没有变更，Vite HMR 不会重新编译该模块。

**修复方案**：把 `MODEL_CONFIGS` 中的 `apiKey` 改为**运行时动态读取**，在 `getModelConfig()` 中注入当前环境变量值。

**解决状态**：⏳ 待修复(用户尚未确认执行)
