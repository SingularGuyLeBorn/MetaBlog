# Session 2026-05-03

## 批次 1：紧急 Bug 修复

### 1. 聊天跨会话队列死锁

**问题发现**：用户在会话 A 发送消息后，切换到会话 B，B 的消息被入队但永远不会消费；A 完成后因 `sessionId !== currentSessionId` 不重置 `isStreaming`，全局死锁。

**根因分析**：`chatStore.ts` 中 `isStreaming` 是全局 `ref(false)`，不是按会话的。`onComplete` 中只有当 `sessionId === currentSessionId.value` 时才重置 `isStreaming`。

**方案选择**：
- ✅ 将 `isStreaming` 改为 `computed(() => streamingSessions.value[currentSessionId.value || ''] || false)`
- ✅ 新增 `streamingSessions = ref<Record<string, boolean>>({})` 按会话跟踪
- ✅ 所有设置/重置不再检查 `sessionId === currentSessionId.value`

**修改文件**：`src/theme/stores/chatStore.ts`

### 2. Tasks 数据重复迁移

**问题发现**：`.data/tasks.json` 中有 16 条任务（4 条 × 4 次重复）。

**根因分析**：`migrateSchedulerTasks()` 用 `existingTypes.has(st.taskType)` 检查重复，但迁移后的任务字段是 `name` 而非 `taskType`，导致每次服务器启动都重复迁移。

**方案选择**：
- ✅ 修复去重逻辑：按 `migratedFrom === 'scheduler-state'` 且 `name === st.taskType` 去重
- ✅ 清理已重复的数据（Node.js 脚本去重）
- ✅ 将 `.data/tasks.json` 迁移到 `.data/tasks/index.json`
- ✅ 将 `.data/memory/scheduler-state.json` 迁移到 `.data/scheduler/state.json`

**修改文件**：`server/routes/internal/tasks.ts`

### 3. Session 重复问题

**问题发现**：左侧会话列表显示 4 个会话（实际 2 个），点击一个会高亮两个。

**根因分析**：`.data/sessions.json` 中同一 ID 出现两次。`storage.saveSession` 在 `knownSessionIds` 丢失时调用 `createSession`，后端 `POST /api/sessions` 没有检查 ID 是否已存在，直接 `unshift` 新记录。

**方案选择**：
- ✅ 后端 `POST /api/sessions` 增加已有 ID 检查：存在则更新，不存在才创建
- ✅ 清理 `.data/sessions.json` 重复数据（保留最新 updatedAt）

**修改文件**：`server/routes/internal/sessions.ts`

## 修复：下拉框问题 + 添加记忆自定义弹窗

### 问题发现
用户：「下拉框问题需要解决了 想想办法吧! 添加记忆不要用浏览器原生 要自己写组件」

之前用 CSS hack（appearance: none + 自定义 SVG 箭头）处理原生 select 样式，效果不稳定，不同浏览器表现不一致，用户要求彻底根治。

### 根因分析
浏览器原生 `<select>` 的渲染由操作系统控制，CSS 覆盖能力有限（尤其 option 的样式几乎不可控）。之前的「增强」只能隐藏箭头、换背景，但无法解决根本问题：
- 下拉列表的样式（圆角、阴影、滚动条）不可控
- 不同浏览器/系统表现差异大
- 重复箭头问题在 Windows 上尤其顽固

### 方案选择
**终极方案：彻底弃用原生 `<select>`，全部改为自定义 Vue 组件。**
- Pros：样式完全可控、跨浏览器一致、支持 icon/搜索等扩展、与 Star River 玻璃拟态设计系统完美融合
- Cons：需要自己实现键盘导航和无障碍属性（当前先保证基础功能，后续迭代增强 a11y）

### 实现过程
1. **新建 `DropdownSelect.vue`**（`src/theme/components/common/`）
   - 完全自定义，无原生 select 元素
   - 支持 `v-model`、`options`（含 `label/value/icon`）、`placeholder`
   - 点击触发器展开/收起下拉菜单
   - 点击外部自动关闭（document click 监听）
   - Escape 键关闭
   - 选中项带 check icon 标记
   - 样式：玻璃拟态背景（backdrop-filter blur）、圆角 14px、莫兰迪色系 hover/active 状态
   - 过渡动画：opacity + translateY + scale
2. **更新 `common/index.ts`** 导出 `DropdownSelect`
3. **改造 `AgentConfigPanel.vue` 添加记忆**
   - 移除 `prompt()` 浏览器原生弹窗
   - 新增 `showAddMemoryModal` + `newMemoryContent` + `newMemoryCategory`
   - 自定义弹窗：textarea（记忆内容）+ `DropdownSelect`（分类选择，5 个分类带 emoji icon）
   - 支持 `Ctrl+Enter` 快捷确认
   - 新增弹窗样式（440px 宽、24px 圆角、与现有 modal 风格一致）
4. **改造 `MemoryManager.vue` 编辑记忆**
   - 弹窗中的分类 `<select>` 替换为 `DropdownSelect`
   - 同样使用带 emoji icon 的 5 个分类选项
