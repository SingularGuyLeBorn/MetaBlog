## 任务 9：AGENTS.md 新增「新增文件必须 git add」规则

### 问题发现

用户原话：「每次新增文件都要 git add」。

### 根因分析

### 方案选择

唯一方案：在 AGENTS.md「Git Commit 规范」中新增「新增文件处理」小节，明确约束。

### 实现过程

在「Git Commit 规范」中新增：
> - **每次新增文件都必须显式 `git add`**，禁止依赖 `git commit -a`
> - 提交前运行 `git status` 确认新增文件已被纳入暂存区
