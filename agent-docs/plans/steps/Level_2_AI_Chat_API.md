# Step 2: 基础 AI CHAT 与 API 暴露

## 1. 概念定位
在搭建好本地知识库（文件系统）后，引入大模型作为智能辅助助手。
目标是构建一个全局视角的智能工作流界面。区别于之前假设的“悬浮球”，当前系统实际采用的是**沉浸式的独立 `/chat` 路由页面布局**，为用户提供一个无干扰的全屏对话体验。同时，这套交互被完整封装为 RESTful API 供任何终端复用。

## 2. 核心功能点与状态
- **功能 1：独立全屏的沉浸式 AI 聊天室 (`/chat` 路由)**
  - **描述**：通过导航进入特定的 Chat 页面 (`ChatPage.vue`)。界面接管了 VitePress 的默认 Layout，以全宽屏形态呈现会话区域。
  - **完成度**：✅ `100% 基础布局已实现`
  - **现有表现**：`Layout.vue` 侦测到路由为 `/chat` 时，隐藏左右侧边栏，只保留 `ChatLayout` 构建的聊天视窗，提供大面积输入与阅读区域。
- **功能 2：流式打字机输出体验 (Streaming)**
  - **描述**：接入并渲染大模型的流式响应。
  - **完成度**：✅ `100% 已实现`
  - **现有交互**：输入内容后，文字逐字以 Markdown 格式流式直出并渲染，并带有 `useChat` 提供的自动滚动 (Auto-scroll) 支持。
- **功能 3：中断与重连机制**
  - **描述**：允许用户在 AI 长篇大论时随时终止生成。
  - **完成度**：✅ `已实现`
  - **现有交互**：`useChat.ts` 暴露了 `interrupt()` 方法。
- **功能 4：API 暴露与持久化**
  - **描述**：通过后端的 Express/Koa 接口暴露流式通信接口。
  - **完成度**：⚠️ `部分实现存在缺陷`。目前的 `useChatHistory` 在前端进行了分组，但在多 Agent 扩展的前夕，其缓存和生命周期控制需要进一步强化以保障不同角色 (Agent) 之间的独立隔离。

## 3. 期望的 UI 交互方式剖析
- **页面布局 (`ChatLayout.vue`)**：
  - **主视窗**：占据屏幕 100% （除 TopBar 外）的高度和宽度。
  - **历史侧边栏**：聊天界面的左侧可能带有（或折叠的）历史会话列表，用于切换不同的对话 (Session)。
  - **消息流**：采用气泡堆叠，区分 User / AI Role。AI 气泡内嵌完整 Markdown 支持。
  - **输入框**：支持多行展开、快捷键发送 (`Enter` / `Shift+Enter`)。
- **操作动线**：
  - 用户点击导航菜单 `AI 助手` -> 路由跳转 `/chat` -> 聚焦底部输入框 -> 发送文本 -> 气泡生成 -> 显示 “Thought：思考中” -> 流式输出回答。

## 4. API 规约 (Input / Output)

| API / 行为 | Endpoint | 请求入参 (Input) | 响应出参 (Output) |
|---|---|---|---|
| **创建新对话** | `POST /api/chat/sessions` | `{ title? : '新会话' }` | `{ id: 'sess_123', title: '...' }` |
| **发送并流式返回** | `POST /api/chat/stream` | `{ sessionId: '123', messages: [{role:'user', content:'...'}] }` | *SSE Stream* `data: {"text": "..."}\n\n` |
| **获取历史记录** | `GET /api/chat/history`| `?sessionId=123` | `{ messages: [...] }`|

## 5. 缺陷与对后续的演进影响
1. **缺陷**：现在的 `Layout.vue` 中 `if (isChatPage)` 强制接管了布局，这套框架固然很沉浸，但这导致**没有办法在阅读文章（非 /chat 路由）时，随时呼出 AI 进行辅助**。
2. **对 Step 4/5 的影响**：这正是为什么我们在 Step 4 (Agent 档案馆) 中，计划要把原本属于 `/chat` 的能力，复用到全局任意页面能呼出的 **抽屉 (Drawer) 或 侧边悬浮** 之中（即新建一个 AgentChat 组件不依赖 `/chat` 路由，让用户边看文档边聊）。这将是提升 Vibe Coding / 阅读体验的质变点。
