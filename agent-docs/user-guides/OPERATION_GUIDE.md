## 场景一：手动文章增删改查

### 1.1 访问文章管理页面

**操作步骤：**
1. 打开浏览器访问 `http://localhost:5173`
2. 在左侧侧边栏看到文章目录树

**UI 变化：**
- 页面加载时，左侧显示文件树
- 中间区域显示欢迎页面或默认文章
- 右侧显示当前文章的目录大纲

**后台数据：**
```
API: GET /api/articles
Response: { success: true, tree: [...] }
```

### 1.2 创建新文章

**操作步骤：**
1. 在左侧文件树中，找到要创建文章的文件夹
2. 鼠标悬停在文件夹上，点击出现的 `+` 按钮
3. 选择 "新建文章"
4. 在弹出的模态框中输入文章标题
5. 点击 "创建"

**UI 变化：**
```
点击前: 文件夹项正常显示
点击后: 弹出液态玻璃模态框
  ┌─────────────────────────┐
  │    ✨ 新建文章           │
  │                         │
  │  标题: [输入框________] │
  │                         │
  │    [取消]  [创建]       │
  └─────────────────────────┘

创建后: 
- 模态框关闭
- 左侧文件树新增文章节点
- 自动导航到新文章编辑页面
- URL 变为 /docs/sections/xxx/new-article
```

**后台数据变化：**
```
API: POST /api/articles/create
Request: { 
  folder: 'docs/sections/posts', 
  name: 'new-article.md',
  title: '新文章标题'
}
Response: { 
  success: true, 
  path: 'docs/sections/posts/new-article.md' 
}

文件系统变化:
- 在 docs/sections/posts/ 下创建 new-article.md
- 文件内容自动生成 frontmatter:
  ---
  title: 新文章标题
  date: 2026-02-26
  ---
```

### 1.3 编辑文章

**操作步骤：**
1. 点击左侧文件树中的文章
2. 在中间阅读区域点击 "编辑" 按钮
3. 使用 Vditor 编辑器进行编辑
4. 按 `Ctrl+S` 或点击 "保存" 按钮

**UI 变化：**
```
点击前: 纯文本阅读模式
点击后: Vditor 编辑器加载
  ┌─────────────────────────────┐
  │ [工具栏: 加粗 斜体 链接...]  │
  │                             │
  │  ┌─────────────────────┐    │
  │  │                     │    │
  │  │   编辑区域          │    │
  │  │   (所见即所得)      │    │
  │  │                     │    │
  │  └─────────────────────┘    │
  │              [保存 Ctrl+S]  │
  └─────────────────────────────┘

保存时:
- 右上角显示 "保存中..." toast
- 保存成功后显示 "✓ 已保存" 2秒后消失
```

**后台数据：**
```
API: POST /api/articles/update
Request: { 
  path: 'docs/sections/posts/article.md',
  content: '# 标题\n\n内容...'
}
Response: { success: true, timestamp: 1234567890 }
```

### 1.4 删除文章

**操作步骤：**
1. 在左侧文件树中，右键点击要删除的文章
2. 选择 "删除"
3. 在确认弹窗中点击 "确认删除"

**UI 变化：**
```
右键后: 显示上下文菜单
点击删除后: 弹出确认模态框
  ┌─────────────────────────┐
  │         ⚠️              │
  │    确认删除文章?         │
  │                         │
  │  "文章标题"             │
  │  删除后无法恢复          │
  │                         │
  │   [取消]  [确认删除]    │
  └─────────────────────────┘

删除后:
- 模态框关闭
- 左侧文件树移除该文章节点
- 如果当前正在查看该文章，跳转到首页
```

**后台数据：**
```
API: POST /api/articles/delete
Request: { path: 'docs/sections/posts/article.md' }
Response: { success: true }

文件系统变化:
- docs/sections/posts/article.md 被删除
```

### 1.5 查看文章列表

**操作步骤：**
1. 点击左侧文件树的文件夹展开/收起
2. 使用顶部搜索框搜索文章

**UI 变化：**
```
展开文件夹:
- 文件夹图标从 ▶ 变为 ▼
- 显示子文件夹和文章列表
- 有过渡动画效果

搜索时:
- 实时显示搜索结果
- 高亮匹配的文字
- 无结果时显示 "未找到相关文章"
```

## 常见问题排查

### Q1: 无法切换 Agent？
**检查步骤：**
1. 确认已点击 Agent 卡片上的 💬 按钮（不是 ⚙️ 配置按钮）
2. 检查浏览器控制台是否有错误
3. 确认该 Agent 状态不是 offline

### Q2: AI 没有调用工具？
**可能原因：**
1. Agent 配置的模式是纯提示词模式（raw）
2. Agent 没有分配相关技能或工具
3. 用户输入的指令不够明确

**解决方法：**
1. 进入 Agent 配置，改为混合模式（hybrid）
2. 为 Agent 添加相关技能（如"写作"技能包含文章工具）
3. 使用更明确的指令，如："使用 create_article 工具创建文章"

### Q3: 定时触发器不生效？
**检查步骤：**
1. 确认后端 Scheduler 服务已启动
2. 检查 Cron 表达式格式是否正确
3. 检查时区设置是否正确

### 文章管理 API
| 操作 | 方法 | 路径 | 参数 |
|------|------|------|------|
| 列表 | GET | /api/articles | - |
| 创建 | POST | /api/articles/create | folder, name, title |
| 更新 | POST | /api/articles/update | path, content |
| 删除 | POST | /api/articles/delete | path |

### Agent 管理 API
| 操作 | 方法 | 路径 | 参数 |
|------|------|------|------|
| 列表 | GET | /api/agents | - |
| 创建 | POST | /api/agents | name, description, avatar, level |
| 更新 | POST | /api/agents/update | id, ...updates |
| 删除 | POST | /api/agents/delete | id |

### 聊天 API
| 操作 | 方法 | 路径 | 参数 |
|------|------|------|------|
| 会话列表 | GET | /api/chat/sessions | - |
| 创建会话 | POST | /api/chat/sessions | title? |
| 发送消息 | POST | /api/chat/stream | sessionId, messages |
| 获取历史 | GET | /api/chat/history | sessionId |
