# 飞书助手 - 可用工具列表

## 文档操作
| 工具 | 说明 |
|------|------|
| `feishuDocCreate` | 创建文档，支持 owner_email/owner_mobile 自动下放权限 |
| `feishuDocRead` | 读取文档内容 |
| `feishuDocMeta` | 获取文档元数据 |
| `feishuDocSearch` | 在云空间中搜索文档 |
| `feishuDocBlocks` | 获取文档块结构（修改/删除前必须先调用） |
| `feishuDocAppend` | 追加内容，支持 `$latex$` 公式转换与代码语言高亮 |
| `feishuDocUpdateBlock` | 更新指定块，支持 `$latex$` 公式转换与样式叠加 |
| `feishuDocDeleteBlock` | 删除指定块 |
| `feishuDocInsertImage` | 插入图片到文档 |
| `feishuDocShare` | 分享文档权限 |
| `feishuDocUnshare` | 取消文档权限 |

## 即时消息
| 工具 | 说明 |
|------|------|
| `feishuImSend` | 发送消息 |
| `feishuUserSearch` | 查找用户 |

## 知识库 (Wiki)
| 工具 | 说明 |
|------|------|
| `feishuWikiSpaceCreate` | 创建知识库 |
| `feishuWikiSpaceList` | 列出知识库 |
| `feishuWikiSpaceGet` | 获取知识库详情 |
| `feishuWikiSpaceUpdate` | 更新知识库 |
| `feishuWikiSpaceDelete` | 删除知识库 |
| `feishuWikiNodeCreate` | 创建知识库节点 |
| `feishuWikiNodeList` | 列出知识库节点 |
| `feishuWikiNodeDelete` | 删除知识库节点 |
| `feishuWikiNodeMove` | 移动知识库节点 |
| `feishuWikiMoveDoc` | 移动文档到知识库 |
| `feishuWikiMemberList` | 获取知识库成员列表 |
| `feishuWikiMemberAdd` | 添加知识库成员 |
| `feishuWikiMemberRemove` | 移除知识库成员 |
