# 02-思考模式

Kimi 提供强大的思考模式（Thinking Mode），模型会在输出最终答案前进行深度推理，特别适合复杂问题求解、数学推理、代码编写等场景。

## 思考模型类型

### 1. 专用思考模型 (kimi-k2-thinking)

使用专门优化的思考模型：

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

# 使用思考模型
response = client.chat.completions.create(
    model="kimi-k2-thinking",  # 专用思考模型
    messages=[
        {"role": "user", "content": "解方程：3x² - 6x + 2 = 0"}
    ],
    max_completion_tokens=4096
)

message = response.choices[0].message

# 获取思考过程 (reasoning_content)
reasoning = getattr(message, "reasoning_content", None)
if reasoning:
    print("🧠 思考过程：")
    print(reasoning)
    print()

print("📄 最终答案：")
print(message.content)
```

### 2. kimi-k2.5 思考模式

Kimi K2.5 支持通过 `thinking` 参数控制思考模式：

```python
# 启用思考（默认）
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[
        {"role": "user", "content": "解这个复杂的数学问题..."}
    ],
    thinking={"type": "enabled"}  # 启用思考
)

# 禁用思考
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[
        {"role": "user", "content": "简单介绍一下你自己"}
    ],
    thinking={"type": "disabled"}  # 禁用思考
)
```

## 思考模式的响应格式

思考模式的响应包含 `reasoning_content` 字段：

```python
{
  "choices": [{
    "message": {
      "role": "assistant",
      "content": "最终答案...",
      "reasoning_content": "详细思考过程..."
    },
    "finish_reason": "stop"
  }]
}
```

## 思考模式 + 流式输出

```python
response = client.chat.completions.create(
    model="kimi-k2-thinking",
    messages=[{"role": "user", "content": "证明勾股定理"}],
    stream=True
)

print("🧠 思考过程 + 答案（流式）：")
for chunk in response:
    delta = chunk.choices[0].delta
    if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
        print(delta.reasoning_content, end="", flush=True)
    elif delta.content:
        print(delta.content, end="", flush=True)
```

## 思考模式 + 工具调用

**注意**：当使用思考模式 + 工具调用时，有以下限制：

1. `tool_choice` 只能设置为 `"auto"` 或 `"none"`
2. 多步工具调用时，必须保留 `reasoning_content` 在上下文中
3. `$webSearch` 官方工具暂不支持思考模式

```python
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[
        {"role": "user", "content": "计算 1234567 是否为质数"}
    ],
    tools=[{
        "type": "function",
        "function": {
            "name": "CodeRunner",
            "description": "执行 Python 代码",
            "parameters": {
                "type": "object",
                "properties": {
                    "code": {"type": "string"}
                }
            }
        }
    }],
    thinking={"type": "enabled"}
)

message = response.choices[0].message

# 处理工具调用
if message.tool_calls:
    # 必须保留 reasoning_content 在下一轮对话中
    messages.append({
        "role": "assistant",
        "content": message.content,
        "reasoning_content": getattr(message, "reasoning_content", None),
        "tool_calls": [tc.model_dump() for tc in message.tool_calls]
    })
```

## Kimi K2.5 思考模式参数限制

| 参数 | 默认值 | 说明 |
|:---|:---|:---|
| `thinking` | `{"type": "enabled"}` | 控制思考模式开关 |
| `temperature` | 1.0 | 固定值，不可修改 |
| `top_p` | 0.95 | 固定值，不可修改 |
| `n` | 1 | 固定值，不可修改 |
| `presence_penalty` | 0 | 固定值，不可修改 |
| `frequency_penalty` | 0 | 固定值，不可修改 |

## 思考模式最佳实践

1. **适合场景**：
   - 数学问题求解
   - 逻辑推理
   - 代码生成与调试
   - 复杂决策分析

2. **不适合场景**：
   - 简单问答
   - 创意写作
   - 需要快速响应的场景

3. **上下文管理**：
   - 多轮对话中保留 `reasoning_content`
   - 长思考链会占用较多 tokens
