# 03-思考模式

## 概述

Kimi 的思考模式（Thinking Mode）允许模型在给出最终答案前进行推理思考，特别适用于复杂逻辑、数学问题和代码编写等场景。

## 思考模式模型

| 模型名称 | 说明 | 上下文长度 |
|---------|------|-----------|
| `kimi-k2-thinking` | 原生思考模式模型 | 256K |
| `kimi-k2-thinking-turbo` | 思考模式快速版 | 256K |
| `kimi-k2.5` | 支持思考开关的多模态模型 | 256K |

## 使用 kimi-k2-thinking 模型

这是最直接的思考模式使用方式：

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

response = client.chat.completions.create(
    model="kimi-k2-thinking",
    messages=[{"role": "user", "content": "解方程组：3x + 2y = 12, x - y = 1"}],
)

message = response.choices[0].message

# 获取思考过程
if hasattr(message, 'reasoning_content'):
    print("🧠 思考过程：")
    print("=" * 60)
    print(message.reasoning_content)
    print("=" * 60)
    print()

# 获取最终答案
print("📄 最终答案：")
print(message.content)
```

## 使用 kimi-k2.5 的思考模式

> ⚠️ **重要提示**: kimi-k2.5 有严格的固定参数限制，设置其他值会导致错误！
> 
> | 参数 | 思考模式 (默认) | 非思考模式 |
> |------|----------------|-----------|
> | `temperature` | **固定 1.0** | **固定 0.6** |
> | `top_p` | 固定 0.95 | 固定 0.95 |
> | `n` | 固定 1 | 固定 1 |
> | `presence_penalty` | 固定 0 | 固定 0 |
> | `frequency_penalty` | 固定 0 | 固定 0 |

Kimi K2.5 通过 `thinking` 参数控制思考模式的开关：

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

# 启用思考模式（默认）
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[{"role": "user", "content": "解释相对论的基本原理"}],
    thinking={"type": "enabled"},  # 明确启用思考
)

message = response.choices[0].message

if hasattr(message, 'reasoning_content'):
    print("🧠 思考过程：")
    print(message.reasoning_content)
    print()

print("📄 答案：")
print(message.content)
```

## 禁用思考模式

对于 kimi-k2.5，可以显式禁用思考模式：

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

# 禁用思考模式
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[{"role": "user", "content": "今天星期几？"}],
    thinking={"type": "disabled"},
)

print(response.choices[0].message.content)
```

## 思考模式参数说明

| 参数 | 类型 | 说明 |
|-----|------|------|
| `thinking` | object | 思考模式控制参数 |
| `thinking.type` | string | `"enabled"` 或 `"disabled"` |

**注意**：kimi-k2.5 的 `thinking` 参数默认值为 `{"type": "enabled"}`。

## 思考模式 + 流式输出

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

response = client.chat.completions.create(
    model="kimi-k2-thinking",
    messages=[{"role": "user", "content": "证明勾股定理"}],
    stream=True,
)

print("🧠 思考过程：")
print("-" * 60)

is_thinking = True
for chunk in response:
    delta = chunk.choices[0].delta
    
    # 思考内容的流式输出
    if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
        print(delta.reasoning_content, end="", flush=True)
    
    # 切换到正式回答
    if delta.content and is_thinking:
        is_thinking = False
        print("\n" + "-" * 60)
        print("📄 最终答案：")
    
    if delta.content:
        print(delta.content, end="", flush=True)
```

## 思考模式与工具调用的注意事项

使用思考模式进行工具调用时，有以下限制：

1. `tool_choice` 只能设置为 `"auto"` 或 `"none"`
2. 多步工具调用时，必须保留 `reasoning_content` 在上下文中
3. 官方 `$web_search` 工具暂时不兼容 K2.5 的思考模式

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

# 思考模式 + 工具调用示例
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[{"role": "user", "content": "计算 15 的平方根"}],
    tools=[{
        "type": "function",
        "function": {
            "name": "calculator",
            "description": "计算器工具",
            "parameters": {
                "type": "object",
                "properties": {
                    "expression": {"type": "string"}
                }
            }
        }
    }],
    tool_choice="auto",  # 只能使用 auto 或 none
    thinking={"type": "enabled"},
)

message = response.choices[0].message

# 保留 reasoning_content 用于后续对话
if hasattr(message, 'reasoning_content'):
    print("🧠 思考过程：", message.reasoning_content)

# 处理工具调用
if message.tool_calls:
    print("🔧 工具调用：", message.tool_calls)
else:
    print("📄 回答：", message.content)
```

## Kimi K2.5 的固定参数

使用 kimi-k2.5 时，以下参数有固定值，无法修改：

| 参数 | 固定值 | 说明 |
|-----|-------|------|
| `temperature` | 思考模式: 1.0, 非思考模式: 0.6 | 不可修改 |
| `top_p` | 0.95 | 不可修改 |
| `n` | 1 | 不可修改 |
| `presence_penalty` | 0 | 不可修改 |
| `frequency_penalty` | 0 | 不可修改 |

设置其他值将导致错误。
