# 06-视频理解

## 概述

Kimi K2.5 支持视频理解能力，可以分析视频内容并回答相关问题。这是 Kimi K2.5 多模态能力的重要组成部分。

## 支持的模型

| 模型名称 | 视频理解支持 |
|---------|-------------|
| `kimi-k2.5` | ✅ 原生支持 |

## 支持的视频格式

- MP4 (`video/mp4`)
- MPEG (`video/mpeg`)
- MOV (`video/mov`)
- AVI (`video/avi`)
- FLV (`video/x-flv`)
- MPG (`video/mpg`)
- WebM (`video/webm`)
- WMV (`video/wmv`)
- 3GPP (`video/3gpp`)

**推荐分辨率**：不超过 2K (2048×1080)

## 基础视频理解示例

```python
import os
import base64
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

# 读取并编码视频
def encode_video(video_path: str) -> str:
    """将视频编码为 base64"""
    with open(video_path, "rb") as f:
        return base64.b64encode(f.read()).decode("utf-8")

video_path = "example.mp4"
video_base64 = encode_video(video_path)
extension = os.path.splitext(video_path)[1].replace(".", "")

# 构建视频 URL
video_url = f"data:video/{extension};base64,{video_base64}"

# 发送请求
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[
        {"role": "system", "content": "You are Kimi, an AI assistant that can understand videos."},
        {
            "role": "user",
            "content": [
                {"type": "video_url", "video_url": {"url": video_url}},
                {"type": "text", "text": "请描述这个视频的内容。"}
            ]
        }
    ],
)

print(response.choices[0].message.content)
```

## 视频 + 图像 + 文本组合

```python
import os
import base64
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

def encode_file(file_path: str) -> tuple[str, str]:
    """将文件编码为 base64，返回 (url, mime_type)"""
    with open(file_path, "rb") as f:
        ext = os.path.splitext(file_path)[1].lower()
        base64_data = base64.b64encode(f.read()).decode("utf-8")
        
        # 确定 MIME 类型
        mime_types = {
            '.mp4': 'video/mp4',
            '.mov': 'video/mov',
            '.jpg': 'image/jpeg',
            '.jpeg': 'image/jpeg',
            '.png': 'image/png',
            '.webp': 'image/webp',
        }
        mime_type = mime_types.get(ext, 'application/octet-stream')
        
        url = f"data:{mime_type};base64,{base64_data}"
        return url, mime_type

# 准备多媒体内容
content_parts = []

# 添加视频
video_url, _ = encode_file("video.mp4")
content_parts.append({"type": "video_url", "video_url": {"url": video_url}})

# 添加图片
image_url, _ = encode_file("screenshot.jpg")
content_parts.append({"type": "image_url", "image_url": {"url": image_url}})

# 添加文本
content_parts.append({"type": "text", "text": "视频中的场景与这张图片有什么关联？"})

# 发送请求
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[
        {"role": "user", "content": content_parts}
    ],
)

print(response.choices[0].message.content)
```

## 视频理解 + 流式输出

```python
import os
import base64
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

# 编码视频
with open("video.mp4", "rb") as f:
    video_base64 = base64.b64encode(f.read()).decode("utf-8")

response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "video_url", "video_url": {"url": f"data:video/mp4;base64,{video_base64}"}},
                {"type": "text", "text": "详细描述视频中发生了什么。"}
            ]
        }
    ],
    stream=True,
)

# 流式接收响应
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

## 视频理解 + 工具调用

```python
import os
import base64
from openai import OpenAI
import json

client = OpenAI(
```

## 使用文件 ID 引用视频

对于大视频文件，建议先上传文件：

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.moonshot.cn/v1",
)

# 上传视频文件
with open("large_video.mp4", "rb") as f:
    file = client.files.create(file=f, purpose="file-extract")

file_id = file.id
print(f"文件 ID: {file_id}")

# 使用文件 ID 进行视频理解
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "video_url", "video_url": {"url": f"ms://{file_id}"}},
                {"type": "text", "text": "总结视频的主要内容。"}
            ]
        }
    ],
)

print(response.choices[0].message.content)
```

## Token 计费说明

视频理解的 token 消耗基于以下因素：

- **关键帧数量**：视频中的关键帧越多，token 消耗越多
- **关键帧分辨率**：分辨率越高，token 消耗越多
- **视频时长**：时长影响关键帧提取数量

建议使用 Token 估算 API 预先计算：

```python
# Token 估算示例
response = client.chat.completions.create(
    model="kimi-k2.5",
    messages=[messages],
    max_completion_tokens=1,
)

print(f"视频理解预计消耗: {response.usage.prompt_tokens} tokens")
```

## 最佳实践

1. **分辨率控制**：建议不超过 2K，更高分辨率不会提升理解效果
2. **文件大小**：大文件请使用文件上传功能
3. **时长控制**：过长视频可考虑分段处理
4. **组合使用**：可以结合图像、文本一起输入
