# 流式输出 (Streaming)

## 功能介绍

流式输出(Streaming)通过 **Server-Sent Events (SSE)** 技术实时返回生成内容，让用户无需等待完整响应即可看到逐步生成的结果，显著提升了交互体验。

### 免费模型支持情况

智谱 AI 提供以下支持流式输出的免费模型：

| 模型 | 模型代码 | 上下文 | 最大输出 | 思考模式 | 思维链支持 |
|:---|:---|:---:|:---:|:---:|:---:|
| GLM-4.7-Flash | glm-4.7-flash | 200K | 128K | ✅ 支持 | ✅ 支持 |
| GLM-4-Flash-250414 | glm-4-flash-250414 | 128K | 16K | ❌ 不支持 | ❌ 不支持 |
| GLM-4.6V-Flash | glm-4.6v-flash | 128K | 32K | ✅ 支持 | ✅ 支持 |
| GLM-4.1V-Thinking-Flash | glm-4.1v-thinking-flash | 64K | 16K | ✅ 内置 | ✅ 支持 |
| GLM-4V-Flash | glm-4v-flash | 16K | 1K | ❌ 不支持 | ❌ 不支持 |

**说明：**
- **思考模式**：指模型是否支持深度思考模式(thinking 参数)
- **思维链支持**：指模型是否会在响应中返回 `reasoning_content`
- `GLM-4.7-Flash`、`GLM-4.6V-Flash` 支持 `thinking` 参数控制思考模式
- `GLM-4.1V-Thinking-Flash` 强制思考，始终返回 `reasoning_content`

---

## 流式输出 vs 非流式输出

| 特性 | 流式输出 (stream=true) | 非流式输出 (stream=false) |
|:---|:---|:---|
| **响应方式** | 逐字/逐句实时返回 | 完整生成后一次性返回 |
| **首 token 延迟** | 极低(毫秒级) | 较高(等待完整生成) |
| **用户体验** | 即时反馈，感知生成过程 | 等待后一次性展示 |
| **适用场景** | 聊天对话、实时展示 | 批量处理、需要完整结果 |
| **连接方式** | SSE (Server-Sent Events) | 标准 HTTP JSON |
| **数据处理** | 需要逐行解析 | 直接解析 JSON |

---

## 适用场景

### ✅ 推荐使用流式输出

1. **聊天对话应用** - 用户输入后立即看到 AI 开始回应
2. **长文本生成** - 文章、故事等创作时实时展示进度
3. **代码生成** - 程序员可立即看到代码结构
4. **教学解释** - 逐步展示解题过程或解释步骤
5. **实时交互系统** - 需要即时反馈的场景

### ❌ 不推荐使用流式输出

1. **批量数据处理** - 需要完整结果进行后续计算
2. **API 代理服务** - 需要缓存完整响应
3. **结果需要精确统计** - 如 token 计数、字数统计
4. **网络不稳定环境** - SSE 连接可能中断

## SSE 事件处理

### SSE 数据格式

流式响应返回的是 **text/event-stream** 格式，每行以 `data: ` 开头：

```
data: {"id":"123","choices":[{"delta":{"content":"你"}}]}

data: {"id":"123","choices":[{"delta":{"content":"好"}}]}

data: {"id":"123","choices":[{"delta":{"content":"！"}}]}

data: [DONE]
```

### 关键字段说明

| 字段 | 说明 |
|:---|:---|
| `data: [DONE]` | 流式输出结束标记 |
| `choices[0].delta.content` | 新增的文本内容 |
| `choices[0].delta.reasoning_content` | 思维链内容(思考模型) |
| `choices[0].finish_reason` | 结束原因(stop/length/null) |

### 解析步骤

```python
def parse_sse_stream(response):
    """解析 SSE 流式响应"""
    for line in response.iter_lines():
        if line:
            line = line.decode('utf-8')
            # 跳过空行
            if line.startswith('data: '):
                data = line[6:]  # 去掉 "data: " 前缀
                
                # 检查结束标记
                if data == '[DONE]':
                    break
                
                # 解析 JSON 数据
                import json
                chunk = json.loads(data)
                
                # 提取内容增量
                delta = chunk['choices'][0].get('delta', {})
                content = delta.get('content', '')
                reasoning = delta.get('reasoning_content', '')
                
                yield content, reasoning
```

## 代码示例

### 示例 1：文本模型流式输出

```python
import requests
import json

def stream_chat_completion(model, messages, api_key):
    """流式对话完成"""
    response = requests.post(
        url="https://open.bigmodel.cn/api/paas/v4/chat/completions",
        headers={
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json"
        },
        json={
            "model": model,
            "messages": messages,
            "stream": True
        },
        stream=True
    )
    
    full_content = ""
    for line in response.iter_lines():
        if line:
            line = line.decode('utf-8')
            if line.startswith('data: '):
                data = line[6:]
                if data == '[DONE]':
                    break
                chunk = json.loads(data)
                delta = chunk['choices'][0].get('delta', {})
                content = delta.get('content', '')
                if content:
                    print(content, end='', flush=True)
                    full_content += content
    
    return full_content

# 使用示例
api_key = "YOUR_API_KEY"
messages = [{"role": "user", "content": "用三句话介绍人工智能"}]
result = stream_chat_completion("glm-4.7-flash", messages, api_key)
```

def stream_thinking_chat(model, messages, api_key):

## 注意事项

### ⚠️ 重要提示

1. **结束标记识别**  
   SSE 流以 `data: [DONE]` 标记结束，必须正确处理此标记以避免解析错误。

2. **空内容过滤**  
   某些 chunk 可能只包含角色信息(如 `{"role":"assistant"}`)或空内容，需过滤处理。

3. **网络中断处理**  
   流式连接可能因网络问题中断，建议实现重试机制。

4. **编码问题**  
   响应使用 UTF-8 编码，确保正确解码以避免乱码。

5. **超时设置**  
   流式输出可能持续较长时间，适当设置请求超时：
   ```python
   response = requests.post(..., stream=True, timeout=(10, 300))
   # (连接超时, 读取超时) 单位：秒
   ```

6. **性能优化**  
   对于高频调用，建议使用连接池：
   ```python
   from requests.adapters import HTTPAdapter
   
   session = requests.Session()
   session.mount('https://', HTTPAdapter(pool_connections=10, pool_maxsize=10))
   ```

## 完整封装示例

```python
import requests
import json
from typing import Iterator, Optional

class ZhipuStreamingClient:
    """智谱 AI 流式输出客户端"""
    
    BASE_URL = "https://open.bigmodel.cn/api/paas/v4/chat/completions"
    
    def __init__(self, api_key: str):
        self.api_key = api_key
        self.session = requests.Session()
    
    def chat_completion(
        self,
        model: str,
        messages: list,
        stream: bool = True,
        thinking: dict = None,
        **kwargs
    ) -> Iterator[dict]:
        """
        流式对话完成
        
        Args:
            model: 模型代码
            messages: 消息列表
            stream: 是否流式输出
            thinking: 思考模式配置(支持 thinking 的模型可用)
            **kwargs: 其他参数
        
        Yields:
            dict: 包含 content, reasoning_content, finish_reason 的字典
        """
        payload = {
            "model": model,
            "messages": messages,
            "stream": stream,
            **kwargs
        }
        
        # 添加思考模式配置(如果提供)
        if thinking:
            payload["thinking"] = thinking
        
        response = self.session.post(
            url=self.BASE_URL,
            headers={
                "Authorization": f"Bearer {self.api_key}",
                "Content-Type": "application/json"
            },
            json=payload,
            stream=stream,
            timeout=(10, 300)
        )
        response.raise_for_status()
        
        if not stream:
            return response.json()
        
        for line in response.iter_lines():
            if not line:
                continue
            
            line = line.decode('utf-8')
            if not line.startswith('data: '):
                continue
            
            data = line[6:]
            if data == '[DONE]':
                yield {'finish_reason': 'stop'}
                break
            
            try:
                chunk = json.loads(data)
                choice = chunk.get('choices', [{}])[0]
                delta = choice.get('delta', {})
                
                yield {
                    'content': delta.get('content', ''),
                    'reasoning_content': delta.get('reasoning_content', ''),
                    'finish_reason': choice.get('finish_reason')
                }
            except json.JSONDecodeError:
                continue
    
    def chat(
        self,
        model: str,
        messages: list,
        print_output: bool = True,
        show_reasoning: bool = True
    ) -> tuple[str, Optional[str]]:
        """
        简化版流式对话，返回完整内容和思维链
        
        Args:
            model: 模型代码
            messages: 消息列表
            print_output: 是否实时打印输出
            show_reasoning: 是否打印思维链
        
        Returns:
            tuple: (最终内容, 思维链内容)
        """
        full_content = []
        full_reasoning = []
        
        # 判断是否支持思考模式
        thinking_models = ["glm-4.7-flash", "glm-4.6v-flash", "glm-4.1v-thinking-flash"]
        thinking_config = None
        if model in ["glm-4.7-flash", "glm-4.6v-flash"]:
            thinking_config = {"type": "enabled"}
        
        for chunk in self.chat_completion(model, messages, thinking=thinking_config):
            if chunk.get('finish_reason'):
                break
            
            content = chunk.get('content', '')
            reasoning = chunk.get('reasoning_content', '')
            
            if reasoning and show_reasoning:
                full_reasoning.append(reasoning)
                if print_output:
                    print(f"\r[思考] {''.join(full_reasoning)}", end='', flush=True)
            
            if content:
                full_content.append(content)
                if print_output:
                    print(content, end='', flush=True)
        
        return ''.join(full_content), ''.join(full_reasoning) if full_reasoning else None


# 使用示例
if __name__ == "__main__":
    client = ZhipuStreamingClient("YOUR_API_KEY")
    
    # 普通流式对话
    content, _ = client.chat("glm-4.7-flash", [
        {"role": "user", "content": "你好"}
    ])
    
    # 思考模型(GLM-4.7-Flash)
    content, reasoning = client.chat("glm-4.7-flash", [
        {"role": "user", "content": "计算 15 * 23"}
    ])
    if reasoning:
        print(f"\n\n思维过程: {reasoning}")
    
    # 强制思考模型(GLM-4.1V-Thinking-Flash)
    content, reasoning = client.chat("glm-4.1v-thinking-flash", [
        {"role": "user", "content": "分析这个逻辑问题"}
    ])
    if reasoning:
        print(f"\n\n思维过程: {reasoning}")
```
