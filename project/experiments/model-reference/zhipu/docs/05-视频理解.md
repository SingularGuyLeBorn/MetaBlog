# 视频理解 (Video Understanding)

## 功能介绍

视频理解(Video Understanding)是智谱AI提供的多模态能力，让模型能够分析视频内容，理解视频中的动作、场景和事件。

> ⚠️ **重要提示**：目前智谱AI的免费模型中，**仅 GLM-4.6V-Flash 支持视频理解功能**。其他视觉模型(如 GLM-4V-Flash、GLM-4V-Plus)仅支持图片理解，不支持视频输入。

## 适用场景

视频理解功能适用于以下场景：

| 场景 | 说明 |
|:---|:---|
| **视频摘要** | 自动生成视频内容摘要，提取关键信息 |
| **内容审核** | 自动检测视频中的不当内容 |
| **动作识别** | 识别视频中的人物动作和行为 |
| **场景理解** | 分析视频发生的场景和环境 |
| **事件检测** | 识别视频中的重要事件和转折点 |
| **视频问答** | 回答关于视频内容的具体问题 |

## 支持的模型

| 模型 | 模型代码 | 上下文 | 最大输出 | 思考模式 | 思维链支持 | 视频限制 |
|:---|:---|:---:|:---:|:---:|:---:|:---|
| GLM-4.6V-Flash | glm-4.6v-flash | 128K | 32K | ✅ 支持 | ✅ 支持 | 200M以内，mp4/mkv/mov |

**GLM-4.6V-Flash 特点：**
- 支持 `thinking` 参数启用思考模式
- 启用思考模式后返回 `reasoning_content`
- 适合需要深度分析的视频理解任务

## 视频格式和限制

### 支持格式
- MP4
- MKV
- MOV

### 限制说明
- **文件大小**：200MB 以内
- **视频时长**：无明确限制，但建议控制在合理范围内以获得更好的理解效果
- **分辨率**：建议保持原始分辨率，系统会自动处理

## API 调用方式

### 端点信息
```
POST https://open.bigmodel.cn/api/paas/v4/chat/completions
```

### 请求格式

视频理解通过在消息中嵌入 `video_url` 来实现：

```json
{
  "model": "glm-4.6v-flash",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "video_url",
          "video_url": {
            "url": "https://example.com/video.mp4"
          }
        },
        {
          "type": "text",
          "text": "请描述这个视频的内容"
        }
      ]
    }
  ]
}
```

### 启用思考模式

```json
{
  "model": "glm-4.6v-flash",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "video_url",
          "video_url": {
            "url": "https://example.com/video.mp4"
          }
        },
        {
          "type": "text",
          "text": "深入分析这个视频的内容和含义"
        }
      ]
    }
  ],
  "thinking": {
    "type": "enabled"
  }
}
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| `model` | string | 是 | 模型代码，必须使用 `glm-4.6v-flash` |
| `messages` | array | 是 | 消息列表 |
| `messages[].role` | string | 是 | 消息角色，`user` 或 `assistant` |
| `messages[].content` | array | 是 | 多模态内容数组 |
| `content[].type` | string | 是 | 内容类型，`video_url` 或 `text` |
| `content[].video_url.url` | string | 是 | 视频URL地址 |
| `content[].text` | string | 是 | 文本内容 |
| `thinking` | object | 否 | 思考模式配置，启用后返回思维链 |

## 代码示例

### Python 示例

```python
import requests
import json

# API 配置
API_KEY = "your-api-key"
API_URL = "https://open.bigmodel.cn/api/paas/v4/chat/completions"

# 请求头
headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

# 基础视频理解
payload = {
    "model": "glm-4.6v-flash",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "video_url",
                    "video_url": {
                        "url": "https://cdn.bigmodel.cn/agent-demos/lark/113123.mov"
                    }
                },
                {
                    "type": "text",
                    "text": "请描述这个视频的内容，包括场景、动作和主要事件。"
                }
            ]
        }
    ]
}

# 发送请求
response = requests.post(API_URL, headers=headers, json=payload)
result = response.json()

# 输出结果
print(result["choices"][0]["message"]["content"])
```

### 使用思考模式进行深度分析

```python
# 启用思考模式
payload_thinking = {
    "model": "glm-4.6v-flash",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "video_url",
                    "video_url": {
                        "url": "https://cdn.bigmodel.cn/agent-demos/lark/113123.mov"
                    }
                },
                {
                    "type": "text",
                    "text": "深入分析这个视频的内容、拍摄手法和传达的信息"
                }
            ]
        }
    ],
    "thinking": {"type": "enabled"}
}

response = requests.post(API_URL, headers=headers, json=payload_thinking)
result = response.json()
message = result["choices"][0]["message"]

# 输出思维链和最终答案
print("🧠 思维链：")
print(message.get("reasoning_content", "无"))
print("\n✅ 最终答案：")
print(message["content"])
```

### 使用 OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://open.bigmodel.cn/api/paas/v4"
)

# 基础视频理解
response = client.chat.completions.create(
    model="glm-4.6v-flash",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "video_url",
                    "video_url": {
                        "url": "https://cdn.bigmodel.cn/agent-demos/lark/113123.mov"
                    }
                },
                {
                    "type": "text",
                    "text": "视频中发生了什么？"
                }
            ]
        }
    ]
)

print(response.choices[0].message.content)

# 启用思考模式
response_thinking = client.chat.completions.create(
    model="glm-4.6v-flash",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "video_url",
                    "video_url": {
                        "url": "https://cdn.bigmodel.cn/agent-demos/lark/113123.mov"
                    }
                },
                {
                    "type": "text",
                    "text": "深入分析这个视频"
                }
            ]
        }
    ],
    thinking={"type": "enabled"}
)

message = response_thinking.choices[0].message
print("思维链:", message.reasoning_content)
print("最终答案:", message.content)
```

## 注意事项

1. **模型选择**：
   - 务必使用 `glm-4.6v-flash` 模型，其他模型不支持视频理解
   - GLM-4.6V-Flash 支持思考模式，可启用 `thinking` 参数获取思维链

2. **视频大小**：
   - 确保视频文件大小在 200MB 以内，超过限制会导致请求失败

3. **视频格式**：
   - 仅支持 MP4、MKV、MOV 格式，其他格式需要先转换

4. **网络稳定性**：
   - 视频理解需要传输较大的视频文件，确保网络连接稳定

5. **处理时间**：
   - 视频分析需要一定时间，响应时间可能比纯文本请求长

6. **URL 可访问性**：
   - 提供的视频 URL 必须公开可访问，模型需要能够下载视频

7. **隐私安全**：
   - 避免上传包含敏感信息的视频到公共URL

8. **Token 消耗**：
   - 视频理解会消耗较多的 Token，请注意用量控制
   - 启用思考模式会额外消耗 Token(reasoning_content 不计费)

## 常见错误

| 错误码 | 说明 | 解决方案 |
|:---|:---|:---|
| 400 | 视频格式不支持 | 将视频转换为 MP4、MKV 或 MOV 格式 |
| 413 | 视频文件过大 | 压缩视频或裁剪至 200MB 以内 |
| 404 | 视频 URL 无法访问 | 检查 URL 是否正确且公开可访问 |
| 429 | 请求过于频繁 | 降低请求频率 |
