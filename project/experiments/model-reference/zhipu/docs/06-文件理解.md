# 文件理解 (File Understanding)

## 功能介绍

文件理解(File Understanding)是智谱 AI 提供的文档分析能力，让模型能够读取、理解和分析多种格式的文档内容。通过 `file_url` 参数传入文档链接，模型可以提取文档中的文本信息并进行智能分析。

> ⚠️ **重要提示**：目前**仅 GLM-4.6V-Flash** 免费模型支持文件理解功能。

---

## 适用场景

### 1. 文档摘要生成
- 快速生成长篇文档的内容摘要
- 提取关键信息和核心观点
- 多文档对比摘要

### 2. 文档问答
- 基于文档内容回答特定问题
- 定位文档中的相关信息
- 多轮对话式的文档查询

### 3. 信息提取
- 从合同中提取关键条款
- 从报告中提取数据和结论
- 结构化信息抽取

### 4. 文档分析
- 财务报表分析
- 学术论文解读
- 法律文件审查

## 支持的模型

| 模型 | 模型代码 | 上下文 | 最大输出 | 思考模式 | 思维链支持 | 文件限制 |
|:---|:---|:---:|:---:|:---:|:---:|:---|
| GLM-4.6V-Flash | glm-4.6v-flash | 128K | 32K | ✅ 支持 | ✅ 支持 | 最多50个，PDF≤50MB |

**GLM-4.6V-Flash 特点：**
- 支持 `thinking` 参数启用思考模式
- 启用思考模式后返回 `reasoning_content`
- 适合需要深度分析的文档理解任务

---

## 支持的文件格式和限制

### 支持的格式
- **PDF** - 便携式文档格式
- **TXT** - 纯文本文件
- **Word** - Word 文档 (.doc, .docx)
- **Excel** - 电子表格 (.xlsx, .xls)
- **PPT** - PowerPoint 演示文稿 (.pptx)
- **JSONL** - JSON Lines 格式

### 文件限制
| 限制项 | 说明 |
|:---|:---|
| 文件数量 | 最多支持 **50 个**文件同时上传 |
| PDF 大小 | 单个 PDF 文件 ≤ **50MB** |
| 其他格式 | 根据实际内容调整 |

## 代码示例

### Python 示例

```python
import requests

API_KEY = "your-api-key"
API_URL = "https://open.bigmodel.cn/api/paas/v4/chat/completions"

def analyze_document(file_url, question="请分析这份文档的内容"):
    headers = {
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json"
    }
    
    payload = {
        "model": "glm-4.6v-flash",
        "messages": [
            {
                "role": "user",
                "content": [
                    {
                        "type": "file_url",
                        "file_url": {"url": file_url}
                    },
                    {
                        "type": "text",
                        "text": question
                    }
                ]
            }
        ]
    }
    
    response = requests.post(API_URL, json=payload, headers=headers)
    return response.json()

# 使用示例
result = analyze_document(
    "https://cdn.bigmodel.cn/static/demo/demo1.pdf",
    "请总结这份文档的主要内容"
)
print(result["choices"][0]["message"]["content"])
```

### 启用思考模式进行深度分析

```python
def analyze_document_deep(file_url, question):
    """使用思考模式进行深度文档分析"""
    headers = {
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json"
    }
    
    payload = {
        "model": "glm-4.6v-flash",
        "messages": [
            {
                "role": "user",
                "content": [
                    {
                        "type": "file_url",
                        "file_url": {"url": file_url}
                    },
                    {
                        "type": "text",
                        "text": question
                    }
                ]
            }
        ],
        "thinking": {"type": "enabled"}
    }
    
    response = requests.post(API_URL, json=payload, headers=headers)
    result = response.json()
    message = result["choices"][0]["message"]
    
    # 返回思维链和最终答案
    return {
        "reasoning": message.get("reasoning_content", ""),
        "content": message["content"]
    }

# 使用示例
deep_result = analyze_document_deep(
    "https://cdn.bigmodel.cn/static/demo/demo1.pdf",
    "深入分析这份文档的核心观点和潜在问题"
)

print("🧠 思维链：")
print(deep_result["reasoning"])
print("\n✅ 最终答案：")
print(deep_result["content"])
```

## 注意事项

### ⚠️ 重要限制

1. **模型限制**
   - 仅 GLM-4.6V-Flash 支持文件理解
   - 其他模型调用 file_url 会报错

2. **不能与其他多模态内容混用**
   - ❌ 不支持同时传入 `file_url` 和 `image_url`
   - ❌ 不支持同时传入 `file_url` 和 `video_url`
   - 如需分析图片中的文档，请先转换为文档 URL

3. **文件访问要求**
   - 文件 URL 必须是**公开可访问**的
   - 需要签名或认证的文件链接无法直接使用
   - 建议使用稳定可靠的 CDN 或存储服务

4. **思考模式使用**
   - GLM-4.6V-Flash 支持 `thinking` 参数启用思考模式
   - 启用后可获得 `reasoning_content` 思维链内容
   - 适合复杂文档的深度分析任务

5. **内容长度限制**
   - 超长文档可能被截断
   - 建议对超长文档进行分段处理

### 最佳实践

1. **文档预处理**
   - 确保文档格式正确，无损坏
   - 扫描件 PDF 需确保文字可被识别(OCR)
   - 大型 PDF 可考虑拆分处理

2. **提示词设计**
   - 明确指定分析需求
   - 提供输出格式要求
   - 多文件分析时说明分析维度

3. **错误处理**
   - 处理文件无法访问的情况
   - 处理文件格式不支持的情况
   - 处理文件内容过大或损坏的情况
