# 07-视频生成

## CogVideoX-Flash 模型

### 模型概述

CogVideoX-Flash 是智谱 AI 推出的 **业界首个免费视频生成 API**，基于 CogVideoX 架构优化，提供高效、便捷的视频生成能力。该模型完全免费调用，适合开发者快速构建视频生成应用。

### 模型规格

| 规格项 | 说明 |
|:---|:---|
| 输入模态 | 文本、图片(可选首帧) |
| 输出模态 | 视频(MP4) |
| 计费方式 | **免费** |
| 生成方式 | **异步 API**(提交任务 → 查询结果) |
| 典型生成时长 | 1-5 分钟 |

### 生成方式

CogVideoX-Flash 采用 **异步 API** 模式：

1. **提交任务** - 调用接口提交视频生成请求，获取 `task_id`
2. **轮询状态** - 定期查询任务状态
3. **获取结果** - 任务完成后，获取视频 URL

### 支持的功能

- ✅ **文生视频** - 通过文本描述生成视频
- ✅ **图生视频** - 以图片作为首帧生成视频
- ✅ **多种分辨率** - 支持多种视频尺寸
- ✅ **可控时长** - 生成固定长度的视频片段

### 适用场景

| 场景类型 | 应用示例 |
|:---|:---|
| **短视频创作** | 社交媒体短视频、营销视频 |
| **动画制作** | 概念动画、演示动画 |
| **视频素材** | 背景视频、转场素材 |

### API 调用方式

**任务提交端点**：`https://open.bigmodel.cn/api/paas/v4/videos/generations`

**任务查询端点**：`https://open.bigmodel.cn/api/paas/v4/async-result/{task_id}`

**请求方式**：POST(提交)、GET(查询)

**认证方式**：Bearer Token

### 基础调用示例(HTTP)

### Python 调用示例

```python
from openai import OpenAI
import time

client = OpenAI(
    api_key="your-api-key",
    base_url="https://open.bigmodel.cn/api/paas/v4"
)

def generate_video(prompt, size="1024x1024", image_url=None):
    """
    生成视频并等待完成
    
    Args:
        prompt: 视频描述提示词
        size: 视频尺寸
        image_url: 首帧图片 URL(可选)
    
    Returns:
        视频 URL 和封面图 URL
    """
    # 1. 提交任务
    print(f"🎬 提交视频生成任务...")
    print(f"   提示词: {prompt}")
    
    body = {
        "model": "cogvideox-flash",
        "prompt": prompt
    }
    
    if image_url:
        body["image_url"] = image_url
    
    response = client.post(
        path="videos/generations",
        cast_to=dict,
        body=body
    )
    
    task_id = response.get("id")
    if not task_id:
        raise Exception(f"提交任务失败: {response}")
    
    print(f"   任务ID: {task_id}")
    
    # 2. 轮询等待完成
    max_attempts = 60  # 最多等待 10 分钟
    for attempt in range(max_attempts):
        time.sleep(10)  # 每 10 秒查询一次
        
        result = client.get(
            path=f"async-result/{task_id}",
            cast_to=dict
        )
        
        status = result.get("task_status", "UNKNOWN")
        print(f"   状态检查 {attempt + 1}/{max_attempts}: {status}")
        
        if status == "SUCCESS":
            video_url = result["video_result"][0]["url"]
            cover_url = result["video_result"][0].get("cover_image_url")
            print(f"✅ 视频生成完成!")
            return video_url, cover_url
        
        elif status in ["FAIL", "FAILED"]:
            raise Exception(f"视频生成失败: {result}")
        
        elif status in ["PROCESSING", "PENDING"]:
            continue  # 继续等待
        
        else:
            print(f"   未知状态: {status}")
    
    raise TimeoutError("视频生成超时")

# 使用示例
try:
    video_url, cover_url = generate_video(
        prompt="一只柴犬在草地上奔跑，阳光明媚，蓝天"
    )
    print(f"\n视频地址: {video_url}")
    if cover_url:
        print(f"封面地址: {cover_url}")
except Exception as e:
    print(f"错误: {e}")
```

### 高级异步处理示例

```python
import concurrent.futures
from typing import List, Dict

class VideoGenerator:
    """视频生成器 - 支持批量和并发"""
    
    def __init__(self, api_key: str):
        self.client = OpenAI(
            api_key=api_key,
            base_url="https://open.bigmodel.cn/api/paas/v4"
        )
    
    def submit_task(self, prompt: str, image_url: str = None) -> str:
        """提交视频生成任务"""
        body = {"model": "cogvideox-flash", "prompt": prompt}
        if image_url:
            body["image_url"] = image_url
        
        response = self.client.post(
            path="videos/generations",
            cast_to=dict,
            body=body
        )
        return response.get("id")
    
    def check_task(self, task_id: str) -> Dict:
        """查询任务状态"""
        return self.client.get(
            path=f"async-result/{task_id}",
            cast_to=dict
        )
    
    def wait_for_completion(self, task_id: str, timeout: int = 600) -> str:
        """等待任务完成"""
        start_time = time.time()
        while time.time() - start_time < timeout:
            result = self.check_task(task_id)
            status = result.get("task_status")
            
            if status == "SUCCESS":
                return result["video_result"][0]["url"]
            elif status in ["FAIL", "FAILED"]:
                raise Exception(f"任务失败: {result}")
            
            time.sleep(10)
        
        raise TimeoutError("任务超时")
    
    def generate(self, prompt: str, image_url: str = None) -> str:
        """生成视频(完整流程)"""
        task_id = self.submit_task(prompt, image_url)
        return self.wait_for_completion(task_id)
    
    def generate_batch(
        self,
        prompts: List[str],
        max_workers: int = 3
    ) -> List[Dict]:
        """批量生成视频"""
        results = []
        
        with concurrent.futures.ThreadPoolExecutor(max_workers=max_workers) as executor:
            futures = {
                executor.submit(self.generate, prompt): i
                for i, prompt in enumerate(prompts)
            }
            
            for future in concurrent.futures.as_completed(futures):
                i = futures[future]
                try:
                    video_url = future.result()
                    results.append({
                        "index": i,
                        "prompt": prompts[i],
                        "status": "success",
                        "url": video_url
                    })
                except Exception as e:
                    results.append({
                        "index": i,
                        "prompt": prompts[i],
                        "status": "failed",
                        "error": str(e)
                    })
        
        return sorted(results, key=lambda x: x["index"])

# 使用示例
generator = VideoGenerator(api_key="your-api-key")

# 单个生成
video_url = generator.generate("猫咪在弹钢琴")

# 批量生成
results = generator.generate_batch([
    "海浪拍打礁石",
    "樱花飘落的街道",
    "烟花绽放的夜空"
])
```

### 任务状态说明

| 状态 | 说明 |
|:---|:---|
| `PENDING` | 任务等待中，尚未开始处理 |
| `PROCESSING` | 任务处理中 |
| `SUCCESS` | 任务成功完成，可以获取视频 URL |
| `FAIL` / `FAILED` | 任务失败 |

### 注意事项

1. **异步模式**：视频生成采用异步 API，需要轮询查询任务状态
2. **生成时间**：通常需要 1-5 分钟，复杂场景可能更长
3. **免费额度**：完全免费调用，但建议合理控制请求频率
4. **提示词质量**：详细的运动描述有助于生成更好的视频
5. **视频格式**：生成的视频为 MP4 格式
6. **视频有效期**：生成的视频 URL 通常有有效期，建议及时下载保存
7. **并发控制**：建议适当控制并发数量，避免过多任务同时提交
