# 需求清单 — 待实现

本文档维护 MetaBlog 所有待实现的功能需求，按功能领域分类。每个需求标注状态、优先级和参考项目。

> **维护规则**：
>
> - 需求完成后从本文档移除，记录到 [completed.md](./completed.md)
> - 新增需求按格式追加到对应分类末尾
> - 定期Review优先级，确保P0不超过5个

---

## 📋 需求格式

```markdown
### [REQ-编号] 需求名称
- **状态**: 待实现 / 设计中
- **优先级**: P0 / P1 / P2 / P3
- **领域**: Harness / Hermes / Execution / Claw / Data / Content / Academic / Platform / Frontend
- **关联层级**: L3 / L4 / L5 / L6
- **描述**: 一句话说明需求目标
- **参考项目**: 具体项目名称
- **核心机制**: 最值得借鉴的设计点(1-2句话)
```
