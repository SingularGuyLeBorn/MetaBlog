## 太阳系概览

我们的太阳系由太阳和围绕它运行的天体组成，包括8颗行星、无数的小行星、彗星和流星。

### 太阳

太阳是太阳系的中心恒星，占据了太阳系总质量的99.86%。它的引力将所有的行星束缚在各自的轨道上。

### 八大行星

| 行星 | 距离(AU) | 特点 |
|------|---------|------|
| 水星 | 0.39 | 最小的行星，表面温差极大 |
| 金星 | 0.72 | 最热的行星，浓厚的大气层 |
| 地球 | 1.00 | 我们的家园，唯一已知有生命的星球 |
| 火星 | 1.52 | 红色星球，拥有太阳系最高的山峰 |
| 木星 | 5.20 | 最大的行星，拥有大红斑 |
| 土星 | 9.58 | 拥有壮观的环系统 |
| 天王星 | 19.22 | 躺着自转的冰巨星 |
| 海王星 | 30.05 | 最远的行星，超音速的风 |

### 小行星带

位于火星和木星之间，包含数百万颗大小不一的小行星，它们是太阳系形成时期的遗留物。

### 彗星

由冰和尘埃组成的"脏雪球"，当它们靠近太阳时，会形成壮观的彗尾。
