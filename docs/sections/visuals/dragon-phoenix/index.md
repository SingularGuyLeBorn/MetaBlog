# Dragon & Phoenix 龙凤呈祥

中国传统中最具象征意义的两种神兽——龙与凤，共同呈现祥瑞之兆。

## 龙凤呈祥

在中国文化中，龙代表阳刚、力量与权威，凤代表阴柔、美丽与高贵。两者结合象征着和谐、繁荣与吉祥。

### 龙

龙是中国文化中最崇高的神兽，象征着：
- **帝王权威** - 古代皇帝自称"真龙天子"
- **祥瑞之兆** - 带来风调雨顺、国泰民安
- **力量与勇气** - 不屈不挠的精神象征

### 凤凰

凤凰是百鸟之王，象征着：
- **高贵典雅** - 皇后的象征
- **涅槃重生** - 浴火重生的生命力
- **和平盛世** - 天下太平的预兆

### 阴阳调和

龙与凤的结合体现了中国哲学中的阴阳思想：
- 龙为阳，凤为阴
- 两者相辅相成，缺一不可
- 象征天地和谐、万物繁荣
