# Black Hole 黑洞

体验宇宙中最神秘的天体——黑洞，探索事件视界和吸积盘的奥秘。

## 黑洞简介

黑洞是时空展现出极端引力效应的区域，其引力之强，以至于没有任何粒子，甚至电磁辐射（如光）能够从中逃逸。

### 事件视界

事件视界是黑洞的边界，一旦越过这个边界，就连光也无法逃脱。这就是为什么我们称其为"黑洞"——它是完全黑暗的。

### 吸积盘

当物质落入黑洞时，会形成一个高速旋转的圆盘——吸积盘。在强烈的摩擦和引力作用下，物质被加热到极高温度，发出强烈的X射线和可见光。

### 引力透镜效应

黑洞的强大引力会弯曲周围的光线，造成引力透镜效应。这就是为什么你在黑洞"背面"也能看到光线——光线被弯曲了。

### 奇点

在黑洞的中心是奇点——一个密度无限大、时空曲率无限大的点。在这里，已知的物理定律都失效了。
