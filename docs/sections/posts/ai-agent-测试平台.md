## 测试说明

### 📦 MCP 工具
- **MCP Math** - 数学计算工具
- **MCP Text Stats** - 文本统计分析
- **MCP System Info** - 系统信息查询
- **MCP Memory** - 内存使用查询
- **MCP Split Text** - 文本分割工具
- **MCP Format JSON** - JSON 格式化

### 🌐 网络工具
- **Fetch URL** - 网页抓取代理
- **GitHub API** - GitHub API 代理

### 📝 文章工具
- **List Articles** - 获取文章列表
- **Read Article** - 读取文章内容

### 🐙 GitHub 工具
- **Repo Info** - 获取仓库信息
- **File Content** - 获取文件内容
- **Commits** - 获取提交历史

## 使用指南

1. 点击 **🚀 一键测试** 按钮测试所有工具
2. 点击分类标题可以折叠/展开该类别
3. 点击单个测试卡片的 **▶ 开始测试** 进行单独测试
4. 点击卡片查看详细测试结果
5. 使用 **☀️/🌙** 切换亮色/暗色主题
6. 右下角 **📋 日志** 面板查看测试日志
