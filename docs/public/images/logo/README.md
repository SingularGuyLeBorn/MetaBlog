## 🎨 设计理念

- **演化层级**：每一层几何结构都代表一个能力阶段。
- **知识连接**：线条与节点的交汇象征全域知识聚合。
- **人文气质**：笔尖与星火的融合体现“代码如电路，诗歌如文学”的追求。
